Doer is a Kanban board experiment for organizing projects and moving work through clear stages.

## Product capabilities

- Organize project work on a visual Kanban board.
- Move tasks through clear workflow stages as work progresses.
- Explore a project-management interface built for the web.

## Screenshots

![Animated Doer Kanban board preview showing work moving through project stages](https://raw.githubusercontent.com/Salvist/doer/master/preview/doer_preview.gif)

## Tech stack

- **Flutter** provides the web application interface and interactive board experience.
- **GraphQL** supports structured communication between the client and server.
