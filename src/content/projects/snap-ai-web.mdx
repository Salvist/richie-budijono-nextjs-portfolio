Snap AI Web is a smaller browser-based version of the original mobile experiment. It explores how the same generation workflow can work as an accessible web experience.

[Open the web experiment](https://snap-ai-68297.web.app/)

## Product capabilities

- Text to image generation.
- Firebase-backed accounts and token refreshes.
- Responsive Flutter web interface.

## Tech stack

- **Flutter** with `flutter_bloc` and `go_router`.
- **Firebase** for authentication, Firestore, storage, functions, scheduling, and hosting.
- **ModelsLab** as the Stable Diffusion provider.
