## The problem

Y Lift, a growing automotive business, needed a modern e-commerce presence and internal tools to run its operations — on top of a legacy codebase that had become difficult for developers to work in.

## What I built

As front-end lead, I delivered the e-commerce website and three internal applications:

- **40+ pages** built in close collaboration with the designer, backed by a library of **100+ reusable components and widgets** so new features composed quickly instead of being rebuilt each time.
- **A legacy migration** — I refactored most of the existing code to be readable and maintainable by other developers, so the team could move faster without fear of breaking things.
- **API alignment** — I worked with the backend team to define API contracts, identify missing data points, and ensure data consistency across the frontend.

## The results

The business went from a fragile legacy frontend to a coherent design system powering four applications — with a component library that made every subsequent feature cheaper to build.
